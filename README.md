# Пушкинская карта · Казань

3D-карта Казани с кинотеатрами, театрами, музеями и концертными залами, где можно оплатить билеты Пушкинской картой.

## Возможности

- 3D-карта, ограниченная районом Казани, где есть площадки; плавный перелёт камеры к выбранному месту
- Карточка площадки: адрес, маршрут в Яндекс Картах, сеансы по дням на неделю вперёд
- Карточка события: обложка, жанр, возраст, длительность, рейтинг, описание, трейлер и все площадки, где оно идёт
- «Рядом со мной»: поиск по адресу или геолокации, ближайшие места с расстоянием и временем в пути
- «Культурный паспорт»: штамп за покупку билета в новом месте, 5 разных мест дают участие в розыгрыше
- Светлая и тёмная тема, адаптивная мобильная версия

## Запуск

Сборка не нужна — это статический сайт. Достаточно любого локального сервера:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Данные

Все площадки и события лежат в `data.js`:

- `image` — ссылка на постер (без неё показывается цветная обложка)
- `trailer` — ID ролика YouTube (без него кнопка открывает поиск на YouTube)

**Важно:** площадки собраны из открытых источников, координаты приблизительные. Рейтинги, сеансы и цены — демонстрационные; перед запуском их нужно заменить на актуальные или подключить API билетного оператора. Оплата и штампы паспорта в текущей версии — демо (штампы хранятся в браузере).

## Технологии

- [MapLibre GL JS](https://maplibre.org/) и тайлы [OpenFreeMap](https://openfreemap.org/) (данные © OpenStreetMap)
- Геокодер [Photon](https://photon.komoot.io/) для поиска адресов
- Чистые HTML, CSS и JavaScript без фреймворков
